# 需求与设计方向

更新：2026-09-22。只记录经过提炼的项目需求，不保留原始通信。

## 已确认

| 项目 | 决定 |
| --- | --- |
| 正式名称 | AI for Chemistry Club |
| 展示简称 | AI4Chem Club（网站展示用，不声称是另行注册的名称） |
| 组织背景 | 学生运营的 Department-associated Group（DAG），Sponsor Department 为 HKUST Department of Chemistry |
| 注册 | 2026-09-01 生效，本期至 2027-08-31；需按年续期 |
| 核心方向 | AI × chemistry；兼顾数学、物理等 AI for Science，以及 AI 本身的基础、方法和工具 |
| 原定宗旨补充 | 学生主导的学术社群；通过 seminars、reading groups、workshops、student sharing 促进学习与实践，鼓励跨学科交流、peer mentoring 及负责任使用 AI；来源与文案差异见 CONTENT |
| 当前首要用途 | 正式介绍社团，并建立能持续补充信息的网站 |
| 次要用途 | 吸引同学了解和参与；第一版不以招募转化为主 |
| 视觉偏好 | 有活力的学生社团风格为主，保留学术感与正式感 |
| 首版语言 | 英文为主（用户已确认）；中文释义用于内部文案审阅 |
| 联系入口 | ai4chemclub@ust.hk；是否增加其他社团邮箱以后决定 |
| 发布平台 | GitHub Pages；拟由社团 GitHub Organization 持有仓库 |
| 维护方式 | 多名维护者使用各自 GitHub 账号，计划与进度写进仓库 |
| 当前授权 | 本地前期准备：仓库、框架、可执行计划；组织创建按用户最新要求延后，可能由老师创建 |
| 当前审阅安排 | 用户随后授权先根据 objectives 修改文案，再交给师兄看；本地简介与活动介绍已更新，具体视觉、措辞及发布仍待确认 |

## 暂定实现选择

- 首版英文为主已经确认，具体英文文案仍是审阅草稿。
- Astro 静态生成 + 原生 CSS。浏览器默认不发送页面 JavaScript。
- 单页介绍；内容增长后再考虑活动详情页。
- 初始配色：深蓝、明亮蓝、酸橙色点缀；几何排版与大标题。具体视觉仍可在下一阶段调整。
- People 框架预留，资料未获公开确认时不显示空成员卡片。
- 不使用学校标志、外部字体、第三方统计、表单、图片生成或虚构活动照片。

## 信息结构

1. 首页：名称、简短定位、About / Activities 入口。
2. About：背景、初衷、关注领域。
3. Activities & Updates：筹备事项、确定的活动、之后的回顾。
4. People：公开资料准备好后展示。
5. Contact：社团邮箱。

## 首版以外

会员登录、数据库、报名后台、收费、在线投稿、聊天机器人、课程管理、完整双语切换、复杂动画均不在当前范围。遇到真实需求时重新评估。

## 关键边界

- `注册生效日` 与 `成立纪念日` 不自动等同。
- “计划组织”不等于已举办、已获审批或已开放报名。
- 初次 workshop 的方向是 AI 基础与 Git/GitHub；具体标题、日期、地点与讲者尚未定稿。
- OSI 相关活动只能按实际状态描述为社团参与/组队参加外部活动，不能写成社团主办。
- 私人通信中的参与者不自动成为公开 committee/advisor 成员。
- 大学名称与标志的使用，需按注册材料中说明的流程确认。

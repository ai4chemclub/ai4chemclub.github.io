## 暂定实现选择

- 首版英文为主，当前具体文案已暂时定稿；逐段内容保存在 REVIEW.md。
- Astro 静态生成 + 原生 CSS。浏览器默认不发送页面 JavaScript。
- 单页介绍；内容增长后再考虑活动详情页。
- 本轮直接改编参考项目的表现方式：Materia Viva 的浮动导航、白色面板、细边框与阴影、大视觉区搭配窄侧栏；FLEX 的品牌色阶、分色方向区块和导航强调。保留 Astro 静态架构。
- 配色：科大蓝 `#003366`、酒红 `#8D3448`、金黄 `#CC9900`、纸底 `#F5F2EB`、面板 `#FCFAF6`、正文 `#292723`。酒红与纸底来自 Materia Viva，不声称是科大标准色。颜色集中在面板、图形与栏目标题，不叠加大面积多色光晕。
- 字体：沿用 Materia Viva 的本地 Avenir Next / Aptos Display 等无衬线标题方向；正文系统无衬线。大标题明确社团名称；避免重复标签和无用的统计数字。
- 结构：首屏介绍下方放大科学主题视觉，右栏承载真实的筹备活动；About 和三个关注方向为浅色分区，Members 为紧凑白卡片，Contact 用酒红面板。手机自动纵向排列。
- 主视觉为本项目自行绘制的装饰性分子/网络 SVG，借鉴参考项目的三维查看区构图。没有材料名称、测量结果或数值，不将其表述为社团研究成果；不带实验数据或虚假的模型控制按钮。
- 主体设计自检（已认可）：通过面板比例、科学主题主视觉、红金蓝分工体现参考项目的方向。保留科大标识和正式介绍；后续细节工作以上述认可基线为约束。

### 主体认可后的细节约束

- 保留上述布局和视觉基线；资产打磨不改变标题、分区、面板大小或背景。
- 方向入口用 Lucide 的烧瓶、轨道、终端图标替换小色块；邮箱和返回顶部使用同套线条图标。图标保留文字搭配、沿用栏目色，不扩展到每个标题或成员卡。
- 原科学 SVG 坐标、颜色和球棍图案原样保留。鼠标移入主面板或键盘聚焦方向链接时，两条虚线有一次 1.2 秒变化；CSS 仅在 `prefers-reduced-motion: no-preference` 下启用，无自动循环和页面 JavaScript。
- 浏览器小图标改为从科学主图提炼的三节点网络，便于小尺寸辨认；它是网站图标草案，不作为新正式社团标识或大学标识。
- 自检原则：新增元素应有识别或操作提示作用，不新增无资料依据的图片、循环粒子、全屏背景动画或交互控件。详细来源见 ASSETS。

```text
[校徽 / 社团简称                          导航]
社团名称                        简介
[大科学主题视觉                  ][活动侧栏]
[三个分色关注方向 / About 内容             ]
[Members 白色成员卡片                     ]
[酒红 Contact 面板                       ]
```

- 设计 skill：[Anthropic frontend-design](https://github.com/anthropics/skills/tree/34040c9c568585f6929bedeaad110ad08f079624/skills/frontend-design)，安装在用户级 skills 目录。本轮已阅读全文，按“计划、对照需求、实现、截图自检”的方法执行；它提供审阅原则，不是设计质量保证。
- 参考 [Minimal Academic Homepage](https://github.com/Xin-Jiaqi/minimal-academic-homepage) 的通用视觉结构，以本项目自己的 Astro / CSS 实现；未导入该仓库未获许可的代码或图片，来源与核对记录见 ASSETS。
- Members 导航始终显示；成员以紧凑白色卡片呈现，照片为空时显示姓名缩写；名单为空时显示一句待补充说明。
- 科大标识使用官方原文件，保持比例，来源见 ASSETS。继续使用本地字体；不添加第三方统计、表单、图片生成或虚构活动照片。

## 信息结构

1. 首页：名称、简短定位、About / Activities 入口。
2. About：背景、初衷、关注领域。
3. Activities & Updates：筹备事项、确定的活动、之后的回顾。
4. Members：成员名录，展示经确认的姓名、职务，以及可选照片和主页。
5. Contact：社团邮箱。

## 首版以外

会员登录、数据库、报名后台、收费、在线投稿、聊天机器人、课程管理、完整双语切换、复杂动画均不在当前范围。遇到真实需求时重新评估。

## 关键边界

- `注册生效日` 与 `成立纪念日` 不自动等同。
- “计划组织”不等于已举办、已获审批或已开放报名。
- 最新 workshop 要求：不使用具体活动名称；概括介绍正在筹备 Git、AI 辅助编程（vibe coding）等技术培训工作坊。栏目描述为 Workshops in preparation，日期、地点与讲者保持未定。
- OSI 相关活动只能按实际状态描述为社团参与/组队参加外部活动，不能写成社团主办。
- 私人通信中的参与者不自动成为公开 committee/advisor 成员。
- 用户已确认本版可使用大学名称与标识；后续若扩展标识用途，重新核对对应范围。

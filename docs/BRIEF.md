## 暂定实现选择

- 首版英文为主已经确认，具体英文文案仍是审阅草稿。
- Astro 静态生成 + 原生 CSS。浏览器默认不发送页面 JavaScript。
- 单页介绍；内容增长后再考虑活动详情页。
- 当前配色：浅灰页面、白色面板、深灰正文、少量蓝色链接；标题和信息密度参照用户指定的学术主页。原明亮蓝与酸橙色方案已替换。
- 参考 [Minimal Academic Homepage](https://github.com/Xin-Jiaqi/minimal-academic-homepage) 的通用视觉结构，以本项目自己的 Astro / CSS 实现；未导入该仓库未获许可的代码或图片，来源与核对记录见 ASSETS。
- Members 导航始终显示；成员以紧凑图文卡片呈现，照片为空时显示姓名缩写；名单为空时显示一句待补充说明。
- 科大标识使用官方原文件，保持比例，来源见 ASSETS。继续使用本地字体；不添加第三方统计、表单、图片生成或虚构活动照片。

## 信息结构

1. 首页：名称、简短定位、About / Activities 入口。
2. About：背景、初衷、关注领域。
3. Activities & Updates：筹备事项、确定的活动、之后的回顾。
4. Members：成员卡片，展示经确认的姓名、职务，以及可选照片和主页。
5. Contact：社团邮箱。

## 首版以外

会员登录、数据库、报名后台、收费、在线投稿、聊天机器人、课程管理、完整双语切换、复杂动画均不在当前范围。遇到真实需求时重新评估。

## 关键边界

- `注册生效日` 与 `成立纪念日` 不自动等同。
- “计划组织”不等于已举办、已获审批或已开放报名。
- 初次 workshop 的方向是 AI 基础与 Git/GitHub；具体标题、日期、地点与讲者尚未定稿。
- OSI 相关活动只能按实际状态描述为社团参与/组队参加外部活动，不能写成社团主办。
- 私人通信中的参与者不自动成为公开 committee/advisor 成员。
- 用户已确认本版可使用大学名称与标识；后续若扩展标识用途，重新核对对应范围。
